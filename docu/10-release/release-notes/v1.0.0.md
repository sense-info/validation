# v1.0.0 發布紀錄

## 版本概要

此版本為專案的初始穩定版本，提供一個獨立的 PHP 驗證函式庫基礎能力。

## 主要功能

- `Validator` 對外 API
- 補齊常見 rule
- nested / wildcard validation
- custom alias 與 message
- custom validator support
- uploaded file validation support

## 變更內容

- 建立 Validator、Validation、ErrorBag 等核心類別
- 整合常見 rule 集合
- 補足 README 使用範例
- 建立初版測試覆蓋

## 使用方式

```php
$validator = new \Rakit\Validation\Validator;
$validation = $validator->validate($_POST, [
    'email' => 'required|email',
    'password' => 'required|min:8'
]);

if ($validation->fails()) {
    print_r($validation->errors()->firstOfAll());
}
```

## 風險

- 需持續補足更多規則測試
- 若使用者需要更強的驗證層，需在應用層擴充

## 後續版本規劃

- 補充更多常用 rule
- 擴展 docs
- 強化錯誤訊息國際化能力
